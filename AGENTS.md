# AGENTS

Task guides for coding agents live in `.agents/skills/<name>/`. Each skill is self-contained (`SKILL.md` + `references/`) and can be copied out and used on its own.

| Task | Guide |
| --- | --- |
| Run a plugin on another machine, device or app (remote runtime, node link, app hosting) | [.agents/skills/rutis-remote-plugin/SKILL.md](.agents/skills/rutis-remote-plugin/SKILL.md) |
| Add a plugin language / runtime to rutis, or make an existing runtime work remotely | [.agents/skills/rutis-new-runtime/SKILL.md](.agents/skills/rutis-new-runtime/SKILL.md) |

Design principles: [docs/design-philosophy.en.md](docs/design-philosophy.en.md) §7. Documentation is kept in two languages (`.md` and `.en.md`).

Design documents follow [docs/design-docs.en.md](docs/design-docs.en.md): each has a section "What developers see", per role, with the output word for word, errors included; one without it is not done.
