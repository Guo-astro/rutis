# rutis 核心承诺登记表

[English](guarantees.en.md) · [质量规范](quality-standard.md) · [质量执行现状](quality-status.md)

本表只登记 rutis 的 **核心承诺（P0 抽象不变量，Q3.1）**——即一旦失效、使用者无法在自己代码里绕过的边界保证：依赖门控、清理恰好一次、失败回滚与旧状态继续工作、按服务名依赖、跨边界显式报错不静默降级、中断显式失败不假成功不自动重试副作用、结束后无残余。

普通契约行为与实现细节不进本表，由对应测试与公开 API 快照直接保护（#1372、#1376）。已删除或撤回的条目直接移出本表，历史留在 `git log` 与 `CHANGELOG`。

CI 的 `links` 任务运行 `node tools/check-guarantees.mjs` 做正向形式核对：本表只含核心承诺、中英两版一致，且“验证”列指出的测试存在并带 `guarantee: <编号>` 标记。
