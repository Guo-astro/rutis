# rutis 0.12.0 (draft)

## New

- **Runtime state lines** ([#274](https://github.com/arcships/rutis/issues/274), [rutis-host](../guide/rutis-host.en.md#what-run-prints)): `rutis-host run` and `dev` print `runtime <name>: down (<reason>)` when a local runtime's (`node`, `py`, `bun`, Go's `go-<binary>`) process ends on its own or the runtime cannot start, the reason saying how the process ended, such as `runtime py: down (exited with signal: 9 (SIGKILL))`; and `runtime <name>: running` when it runs again. Before, only its rows going back to `waiting for its services` showed it. Runtimes the host stops (the host stopping, a Go runtime stopping when idle) print nothing. Rust library: `rutis-loader` gains `GoRuntimesHandle::states` (each Go runtime's state, without reading the binaries).
- **Changing the configuration while it runs** ([#274](https://github.com/arcships/rutis/issues/274), [rutis-host](../guide/rutis-host.en.md#changing-the-configuration-while-it-runs)): `rutis-host run` reads `rutis.json` again on SIGUSR1 on Unix (systemd: `ExecReload=/bin/kill -USR1 $MAINPID`); with `--watch-config` (off by default) it does when the file's content changed and stayed the same for 500 milliseconds, the way for Windows and Kubernetes ConfigMaps. All or nothing: the new rows are checked first, and a row failing after the replacement brings the old rows back; a broken configuration leaves the old one running and prints `rutis-host: reload rejected: <reason>; nothing changed`, an applied one `rutis-host: reloaded <file> (<n> rows changed)`. Rows added, removed and changed apply at once, those of an `instanced` group in every instance there is; a local runtime removed stops once its rows unloaded. `format`, `id`, `listen`, `runtimes.go`, `runtimes.remote` (`listen` and `instances` included) and a local runtime added or with changed settings cannot change this way: refused, saying to restart the host. SIGHUP is still a termination signal. Credentials are now read from the environment when a link dials or a far end dials in, so a peer row a reload adds connects too.
