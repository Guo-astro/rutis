# rutis 0.16.0

[中文](0.16.0.md) · [0.15.1 release notes](0.15.1.en.md)

0.16.0 keeps the flat event bus introduced in 0.15.1 and removes the compatibility shims that release needed to stay a patch. It also carries the fixes that were ready since 0.15.1.

## Events

- **One flat bus.** Every listener of a name on a root's bus receives the event, whatever its instance, runtime or linked node; a scope is a descriptor for filters, not a delivery rule. This is the 0.15.1 behaviour, unchanged.
- **The 0.15.1 shims are gone.** `Dispatch::scope`, `scope_contains`, the SDK `inScope` / `within` / `events.Within` helpers, Node's `h.at(scope)` and Python's `Bus.emitter(scope)` are removed. See [migrating to 0.16](../migration-0.16.en.md).
- Node links still see only the names their `export` / `import` lists carry; imported entries are not relayed.

## Fixes

- **`#[rutis::service]` methods with `#[cfg]`** are checked only in the builds that contain them; the error follows the method's and impl's cfg ([#591](https://github.com/arcships/rutis/pull/591)).
- **Generic alias arguments in exports** are resolved where they are written, so `Result<Thing>` declared through a `pub type` finds `Thing` ([#598](https://github.com/arcships/rutis/pull/598)).
- **`rutis-host dev` with compiled rows** reloads Python/TypeScript rows when only their sources change, and still rebuilds Go/Swift when their sources change ([#588](https://github.com/arcships/rutis/pull/588)).
- **`Ctx::is_shutting_down()`** reads the root's shutdown flag without building a diagnostic snapshot; loader instance creation uses it ([#608](https://github.com/arcships/rutis/pull/608)).

## Compatibility

- The event wire format is unchanged. 0.15.1 and 0.16.0 hosts and runtimes connect, but an end still on 0.15.1 keeps its own scope filtering; upgrade every end for flat delivery everywhere.
- Rust and SDK users who called the removed scope helpers must migrate; `ListenerInfo::scope` and `Ctx::scope()` stay.
- The `events/scope` and `events/hub-scope` guarantees remain withdrawn; `events/flat` and `events/hub-flat` are the current ones.

## Packages

All of these are at **0.16.0**: on crates.io `rutis`, `rutis-macros`, `rutis-bridge`, `rutis-loader`, `rutis-host`, `rutis-sdk`, `rutis-dylib`, `rutis-dylib-meta`, `rutis-dylib-launcher`; on npm `@arcships/rutis`, `@arcships/rutis-runtime`, `@arcships/rutis-bun`, `@arcships/rutis-host` and the five platform packages; on PyPI `rutis`, `rutis-host`; the Go module `github.com/arcships/rutis/go/rutis` (tag `go/rutis/v0.16.0`); the Swift package (`v0.16.0`); Kotlin `io.github.arcships:rutis` and `io.github.arcships:rutis-ksp`; the `rutis-host` binaries on the release page.
