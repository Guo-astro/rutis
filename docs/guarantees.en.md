# rutis core promise registry

[中文](guarantees.md) · [Quality standard](quality-standard.en.md) · [Quality status](quality-status.en.md)

This registry lists rutis's **core promises (P0 invariants, Q3.1)** only — guarantees that users build on and cannot work around when they fail: dependency gating, exactly-once cleanup, rollback on failure with the old state still working, depending on service names rather than implementations, explicit failure across boundaries instead of silent degradation, explicit failure on interruption without false success or automatic retries of side effects, and nothing left behind on exit.

Ordinary contract behaviours and implementation details are not listed here; they are covered by their tests and public API snapshots directly (#1372, #1376). Withdrawn entries are removed from this table; history stays in `git log` and `CHANGELOG`.

CI's `links` job runs `node tools/check-guarantees.mjs` as a forward form check: every row here is a core promise, matches across both languages, and every test listed in its verification column exists and carries a `guarantee: <id>` marker.

## Counts

- Core promises total: **40** (33 verified, 7 partly verified, 0 not verified).
- Pre-release check (Q9.4.4): unverified core promises must be **0**.
