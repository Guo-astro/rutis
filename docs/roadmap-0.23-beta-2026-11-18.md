# 0.23 beta

状态：beta 定义，2026-11-18。跟踪：[#694](https://github.com/arcships/rutis/issues/694)（版本规划）、[#183](https://github.com/arcships/rutis/issues/183)（质量控制）。

0.23 是 1.0 前的 **beta**：把 0.22 暴露出来的残余问题收干净，做一次会话协议版本升级，并把其余公开契约冻结到可以长时间兼容的形态。

## beta 的含义

- **冻结的契约**：插件 API 3、`rutis.json` 的 `format` 1；Rust 公开 API 不删除、不改名。这些是插件作者直接看到的部分。
- **会话协议从 4 升到 5**：0.23 允许一次协议版本升级，解决取消后回复和异步等待图的问题；旧运行时不能与新运行时混跑，同一部署要一起升级。配《迁移到 0.23》中英两份。
- **可以做**：缺陷、竞态与顺序修复；平台差异修复；新增 API、可选字段、可选能力；协议 5 的语义修改；性能、测试、形式化证据、文档与 CI。
- **不在 0.23 做**：删除或改名插件 API、改变 `format` 1 的默认语义、要求插件作者改写代码；协议 5 之外不引入第二轮破坏性变化。

## 发布条件

0.23.0 发布前必须满足：

- 0.23 milestone 无 P0/P1 缺陷；
- `release.yml` 的 dry run 全绿（五平台 package/install、Windows dylib、Swift 用例）；
- 一次完整 nightly 全绿；
- 两台机器网络冒烟；
- 发布说明与《迁移到 0.23》中英两份就绪；
- 仍未关闭的明确不保证项，在发布说明的「已知不保证」里列出。

## 明确不在 0.23

- 1.0 的长期兼容承诺与 API 稳定化流程；
- 协议 5 之外的新一轮破坏性变化；
- 需要插件作者改写代码的重新设计。
