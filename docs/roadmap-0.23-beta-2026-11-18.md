# 0.23 beta

状态：beta 定义，2026-11-18。跟踪：[#694](https://github.com/arcships/rutis/issues/694)（版本规划）、[#183](https://github.com/arcships/rutis/issues/183)（质量控制）。

0.23 是 1.0 前的 **beta**。它的目标不是再引入一轮破坏性变化，而是把 0.22 暴露出来的残余问题收干净，并把公开契约冻结到可以长时间兼容的形态。

## beta 的含义

- **冻结的契约**：插件 API 3、会话协议 4、`rutis.json` 的 `format` 1；Rust 公开 API 不删除、不改名。
- **可以做**：缺陷、竞态与顺序修复；平台差异修复；新增 API、可选字段、可选能力（默认关闭）；不改变现有语义的协议澄清；性能、测试、形式化证据、文档与 CI。
- **不在 0.23 做**：删除或改名公开 API、改变默认行为、要求现有插件迁移。确实需要 breaking 的，留到 1.0 单独决定并配迁移指南。
- **兼容方式**：新旧运行时可以混用；旧运行时保持自己的旧行为；新能力通过能力声明或显式配置打开。

## 发布条件

0.23.0 发布前必须满足：

- 0.23 milestone 无 P0/P1 缺陷；
- `release.yml` 的 dry run 全绿（五平台 package/install、Windows dylib、Swift 用例）；
- 一次完整 nightly 全绿；
- 两台机器网络冒烟；
- 发布说明与必要的迁移指南就绪；
- 仍未关闭的明确不保证项，在发布说明的「已知不保证」里列出。

## 明确不在 0.23

- 1.0 的长期兼容承诺与 API 稳定化流程；
- 需要破坏现有插件或宿主的重新设计；
- #1040 若不能在不破坏现有行为的前提下收口，就只记录边界，不在 beta 里强推。
